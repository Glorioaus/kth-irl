## 关键结论

- “三代版本”并不等于“三个附件”。同名`v0.1.5`多次发送，必须带发送时间和hash区分。
- 已找回7月25日v0.1.4、7月31日v0.1.5预览、8月2日/8月8日/8月28日开发包及8月28日预览包。
- 7月25日、499.9 KB的v0.1.4就是用户截图的最早交付，已找到并保存。其wheel内66个Python文件共48,944物理行，去空行45,438行。“1万多行”与完整包口径不符，不能因此声称最早版本未找到。
- 7月17日两份早期云文档已全文读取：PRD v1.3、路线图v1.1。它们是最初产品需求的重要来源，不再遗漏。
- 9月1日“成功日志参考包”值得保留，但只支持历史macOS影子运行的结构对照，不证明所交Windows包或当前新运行层已经成功。
- 当前批准wheel及`codex/runtime-rebuild`主线未变。本次不把8月28日新版自动提升为新方法基线，不把历史聊天当成真实调用授权。
